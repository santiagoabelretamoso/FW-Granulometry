A single workspace

From raw grain-size data
to interpretable plots.

FW-Granulometry organizes the granulometric workflow in one graphical interface, keeping the analytical steps visible and editable without requiring users to modify the source code.

01

Sieve

Load Excel datasets expressed in φ classes, calculate granulometric parameters and compare samples or groups.

Plot sample statistics directly over classification diagrams and export publication-ready figures. The Graphic module extends this workflow with editable vector fields.
