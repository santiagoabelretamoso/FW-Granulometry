A single workspace

From raw grain-size data
to interpretable plots.

FW-Granulometry organizes the granulometric workflow in one graphical interface. Combine sieve and laser data, build hybrid distributions, produce plots and extend the interpretation with componentry analysis.

01

Sieve

Load sieve data in φ classes from Excel and calculate granulometric parameters for individual samples or groups.

Coarse fractions · φ scale
02

Laser

Import laser diffraction measurements in μm, convert them to a granulometric framework and integrate the fine fraction into the project.

Fine fractions · μm → φ
03

Hybrid

Combine sieve and laser data from the same sample to build a hybrid distribution across coarse and fine fractions.

Combined dataset

Depositional interpretation

Classical discrimination diagrams for depositional interpretation.

Plot samples over classical mean-sorting frameworks used for depositional interpretation, including Walker (1971, 1983), Gençalioğlu-Kuşcu et al. (2007) and Pardo et al. (2009).

The Graphic module extends this workflow with editable vector fields and publication-oriented figure control.
Componentry

Componentry lives inside the project.

FW-Granulometry 2.0 can connect granulometric distributions with componentry data. Work by fraction, classify particles, inspect compositions and preserve the connection to the source sample.
